一、程序基本信息
程序名：SUN.exe
开发语言：Delphi（FastMM4、.pas、.dpr）
运行平台：Windows 桌面
架构：桌面客户端 + 内嵌 IE 浏览器（IWebBrowser2）
产品：SUNLIKE 系列 ERP（进销存 + 生产 + 财务一体化）
二、数据库信息（SQL Server）
3. 核心表（业务表前缀）
PSWD：用户表（账号 / 密码 / 权限）
COMP：公司 / 账套表
CUST：客户
SALM：业务员
PRDT：产品 / 物料
WH：仓库
BOM：物料清单（生产）
MF_xxx：主档表
TF_xxx：交易 / 单据表
SH_xxx：单据头
ACCN：会计科目
CUR：币种
TAX：税率
三、用户权限系统（最关键）
1. 用户表关键字段
COMPNO：公司编号
USR：账号
PWD：密码
MNG：管理员
B_DAT、E_DAT：有效期
DEP：部门
COMP_BOSS：老板账号
LOCK_TIMES：登录锁定
2. 权限 SQL（登录验证）
plaintext
Select A.PWD,B.NEWVERSION From PSWD A 
Left Outer Join COMP B On A.COMPNO=B.COMPNO
Where A.COMPNO='xxx' And A.USR='xxx'
四、核心业务模块（完整 ERP）
1. 采购模块
PO（采购单）、PRD（采购价）、SUP（供应商）
2. 销售模块
SO（销售单）、CUST（客户）、SALM（业务员）
3. 库存模块
WH（仓库）、PRDT（物料）、BOM（BOM 表）
入库、出库、盘点、调拨
4. 生产模块（MRP）
BOM、MF_MO（生产单）、TF_MO（生产明细）
MRP 运算、物料需求
5. 财务模块
ACCN（科目）、GL（总账）、CUR（币种）、TAX（税务）
应收、应付、成本、总账
6. 单据类型（关键字）
PO：采购、SO：销售、BOM：生产、QC：质检、CHK：审核、BIL：单据
五、数据库核心 SQL（重构重点）
1. 用户密码相关
plaintext
UPDATE PSWD SET PWD=...
SELECT USR,PWD FROM PSWD
2. 单据更新（采购 / 销售 / 库存）
plaintext

UPDATE MF_BOM SET ...
UPDATE CUST SET ...
3. 库存扣减 / 成本计算
plaintext

4. 存储过程（系统核心）
TAB_COLUMNS（表结构）
GetPk_SUN（主键）
CreateResDict（资源字典）
六、界面信息（Delphi 控件）
TForm、TMenu、TEdit、TGrid、TButton
内嵌浏览器：IWebBrowser2、SHDocVw

这是一套 Delphi 开发、SQL Server 数据库、Windows 桌面版 SUNLIKE ERP，包含完整进销存 + 生产 MRP + 财务 + 权限管理，核心表有用户表 PSWD、公司表 COMP、客户 / 产品 / 仓库 / 单据表，内嵌浏览器，支持多账套、多用户权限。
