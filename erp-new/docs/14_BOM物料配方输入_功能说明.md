## 功能清单

- [x] 列表：查询 BOM代号 / 母件品号 / 版本；创建日期区间；明细网格列配置
- [x] 新增/编辑：表头母件+版本+数量；表身子件/用量/损耗率
- [x] **存盘即审核**（写入 `CHK_MAN` / `CLS_DATE`）
- [x] 已审核 **仍可修改、可删除**（SUNLIKE BOM 配方主档行为）
- [x] 母件/子件选货品联动名称、单位、规格、仓号
- [x] BOM代号默认建议 `母件-版本`

## 验收要点

1. 侧栏「基础资料 → BOM物料配方」可进入列表
2. 新增：选母件、填版本、加表身子件，**存盘后状态为已审核**
3. **已审核单据仍可编辑并再次存盘**
4. 同一母件+版本不可重复建 BOM
5. 子件不可与母件品号相同

## 验收结论

**✅ 通过**（2026-05-27）
