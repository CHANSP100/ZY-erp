# 17 生产需求分析单（MrpABA / MF_MP + TF_MP1 + TF_MP2 + TF_MP3）

## 路径

- 页面：`/mrpaba`
- 表头：`MF_MP`
- 表身：`TF_MP1`（需求分析明细）、`TF_MP2`（采购建议）、`TF_MP3`（制令建议）
- 对照表：`analysis/字段对照/生产需求分析单.md`（✅ 已确认 2026-05-27）

## 本期功能

**表头：** 分析单号、分析日期、需求日期、部门、受订单号、分析仓库、单据类别、摘要

**表身 TF_MP1：** 成品代号、品号、品名、特征、库位、单位、受订单号、预交日、受订量、未交量、安全存量、在途量、在制量、**未发量（QTY_ON_RSV）**、需求量、外购量、请购量、配方号、母件、采购需求否、摘要

**表身 TF_MP2：** 品号、品名、特征、库位、厂商、单位、**建议量**、外购量、采购单价、采购本位币、预交日、受订单号、采购单号、批号、币别、对方货号、摘要

**表身 TF_MP3：** 制造成品、品名、特征、库位、单位、建议量、制令量、预开工日、预完工日、部门、制令单号、配方号、母件、受订单号、预交日、托外注记、摘要

**业务：**

- 列表查询 + 新增/编辑/删除
- **从受订单转入**（已审核受订单）
- **分析**按钮：重算 TF_MP1 并生成 TF_MP2/TF_MP3
- **存盘即自动审核**；反审核后可再改
- 审核后回写受订单表头 `MF_POS.CLS_MP_ID='T'`
- **转制令**：已审核且 TF_MP3 有行时，生成制令单并回写 `MO_NO`

**本期不做：** 表头 SAL_NO/PRC_MAN/BUY_MAN/PRD_OUT/OVER_RTO（对照表二期）；转采购单（API 待补）
