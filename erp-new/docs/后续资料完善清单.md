# 后续流程资料 — 建议完善项

您已提供的 `01中类.txt`、`02货品基础资料.txt` 足够启动首期原型。若要接近旧 ERP 完整度，建议按菜单补充以下内容。

---

## 一、所有菜单通用（强烈建议）

| 项 | 说明 | 示例 |
|----|------|------|
| **界面截图** | 每个栏位、页签、按钮各 1 张 | 与 `ERP流程确认/` 模板一致 |
| **字段清单** | 每个输入框对应「必填/选填/自动」 | 表格式：栏位中文名 → 是否必填 → 默认值 |
| **按钮与快捷键** | 存盘、删除、查询、打印、审核 | 「点存盘后是否关闭窗口」 |
| **校验规则** | 重复、长度、停用后能否引用 | 中类停用后能否建新货品 |
| **列表操作** | 修改、删除、复制、导出 | 双击是修改还是查看 |

## 二、中类（`01中类.txt` 可补充）

您已写清：**树 + 列表 + 新增弹窗 + 上层开窗 + 停用日期**。

| 待补充 | 原因 |
|--------|------|

## 三、货品基础资料（`02货品基础资料.txt` 可补充）

您已写清：**中类 → 自动品号 → 品名规格单位 → 其他页签 → 图片文档 → 存盘**。

| 待补充 | 原因 |
|--------|------|
| **各页签完整字段** | PRDT 约 170 字段，首期只做了 15 个 |
| **品号后缀规则** | `11→1103`、`35→3500` 后缀不全是 `03`，需业务规则或参数表 |

## 五、技术决策（CONFIRM-05 仍空）
