# 请购单（InvAQ）

| 项 | 值 |
|----|-----|
| 菜单代码 | InvAQ |
| 路由 | `/sq` |
| 表头 | MF_SQ |
| 表身 | TF_SQ |
| API | `/api/purchase-requisitions` |
| 验收 | ✅ 通过（2026-05-24） |

## 本期

- 表头：请购日期、单号、请购部门、采购对象、请购人、预交日、币别、采购部门、备注
- 表身：品号、品名、特征、单位、数量、单价、预估金额、预交日、用途、已采购量（只读）
- 单号规则：`SQ` + 年月 + 4 位流水
- 金额：表身 `数量 × 单价`，表头汇总 `amtn`

## 转出采购单（已实现）

- 采购单 `/po` → **从请购单转入**（同采购对象、未转完行）
- 存盘回写 `TF_SQ.QTY_PO`；删改采购单回滚已采购量
