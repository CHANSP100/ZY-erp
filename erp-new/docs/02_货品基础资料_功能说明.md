# 货品基础资料（FasECA / 表 PRDT）

## 操作流程（与您的 `02货品基础资料.txt` 对齐）

1. 选择**中类**（下拉或「开窗」列表）
2. 系统自动生成**货品代号**（同旧规则：`2303-0187` = 中类 `23` + 后缀 `03` + 流水）
3. 输入品名、规格、单位
4. **其他**页签：预设仓库、有效天数、安全存量、库存上限
5. **图片/文档**页签：上传
6. **存盘**

## 首期字段

| 页签 | 字段 | 旧字段名 |
|------|------|----------|
| 基本 | 货品代号、中类、品号后缀、品名、规格、单位、简称 | PRD_NO, IDX1, IDX2, NAME, SPC, UT, SNM |
| 其他 | 预设仓库、有效天数、安全存量、库存上限、摘要 | WH, VALID_DAYS, QTY_MIN1, QTY_MAX, REM |
| 附件 | 图片、文档 | PIC→文件路径, OLEFIELD→文档路径 |

## 流水号规则（已实现）

- 若该中类已有品号：取最大品号的前缀（如 `3500`）+ 流水 +1
- 若无：默认前缀 = `中类代号 + 后缀`，后缀默认 `03`（可在界面改，如 `35` 类用 `00`）

## 验收清单

- [ ] 选中类 `23`，新货品代号约为 `2303-xxxx`（与库内最大号 +1）
- [ ] 品名必填，存盘后列表可见
- [ ] 预设仓库下拉为 MY_WH 九条
- [ ] 图片双击上传后可预览
- [ ] 文档上传后可打开链接
