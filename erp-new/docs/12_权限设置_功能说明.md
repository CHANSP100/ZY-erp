## 路由

- 页面：`/sys/auth`
- API：`/api/sys-auth/*`（管理员维护；`my-permissions` 任意登录用户可读）

## 功能

| 页签 | 说明 |
|------|------|
| 用户列表 | PSWD 主档字段维护（代号、名称、密码、部门、管理员、启用/停用等） |
| 菜单权限 | PSWD1 矩阵：查询/新增/修改/删除/打印 |
| 部门数据权限 | DEPRO_SET + 用户 DEPRO_NO |
| 仓库数据权限 | sys_user_wh（空=全部仓库） |

## 权限生效

- 登录后返回 `user.permissions`
- 侧栏按 **查询(DSP)** 过滤
- 路由无 DSP 时跳转首页
- API 按 HTTP 方法映射 APD/UPD/DEL/DSP
- 仓库列表 API 按 `sys_user_wh` 过滤
