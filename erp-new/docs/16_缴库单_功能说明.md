# 缴库单（MrpAFC）功能说明

| 项 | 值 |
|----|-----|
| 菜单代码 | MrpAFC |
| 对照表 | `analysis/字段对照/缴库单.md`（✅ 已确认 2026-05-27） |
| 表头/表身 | MF_MM0 / TF_MM0 |
| 路由 | `/mrpafc` |
| API | `/api/warehouse-deposits` |

## 业务要点（SUNLIKE 9.0）

- `MM_ID='MM'` 缴库；审核且 `FIN_ID='Y'` 时回写 `MF_MO.QTY_FIN`
- 成品库存入库（`PRDT1.QTY` 增加）
- 从制令单转入：默认数量 = 制令数量 − 已缴库量
- 支持多行、多次开窗、一次多选制令
- 超缴允许；审核前弹窗提醒

## 页面

- 列表：`WarehouseDepositPage.vue` + `MrpAFC_BILL` 网格
- 编辑：`WarehouseDepositFormView.vue` + `useWarehouseDepositBill.ts`

## 依赖

- 制令单 MrpAC（`/mo`）须已审核且未结案方可转入
