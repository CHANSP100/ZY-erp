# 中类代号（OthHZYQD / 表 INDX）

## 界面

- **左侧**：中类树（按 `IDX_UP` 上下级）
- **右侧**：中类列表，支持按树节点筛选
- **新增**：弹窗录入后点「存盘」

## 字段（首期）

| 字段 | 说明 | 必填 |
|------|------|------|
| IDX_NO | 中类代号 | 是 |
| NAME | 名称 | 否 |
| IDX_UP | 上层中类 | 否（开窗选择已有代号） |
| STOP_DD | 停用日期 | 否 |
| REM | 备注 | 否 |
