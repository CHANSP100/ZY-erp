# 客户供应商区域（FasECG / 表 AREA）

## 界面

- **左侧**：区域树（按 `AREA_UP` 上下级）
- **右侧**：区域列表，支持按树节点筛选
- **新增/编辑**：弹窗录入后点「存盘」

## 字段（首期）

| 字段 | 说明 | 必填 |
|------|------|------|
| AREA_NO | 区域代号 | 是 |
| NAME | 名称 | 是 |
| AREA_UP | 上层区域 | 否（开窗选择已有代号） |
| STOP_DD | 停用日期 | 否 |
| REM | 备注 | 否 |

## 业务规则

- 根节点代号 `00000000` 不显示在列表
- 上层区域不可选自身或下级
- 已被客户厂商引用的区域不可删除
- 存在下级区域时不可删除
