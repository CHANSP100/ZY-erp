# SUNLIKE9.0 核心业务基准规范（全套复刻版）

## 文档说明

1. **本文档为项目唯一业务逻辑基准**。所有页面、单据、参数、联动逻辑强制 **1:1 复刻天心 SUNLIKE9.0 原生规则**，禁止套用金蝶、用友及通用 ERP 逻辑，禁止 AI 自主创作业务规则。
2. **项目整体技术视觉拆分**：
   - **UI 界面** = 最新金蝶云星空商用风格
   - **业务内核** = 纯原生 SUNLIKE9.0 逻辑
   - 颜值标准化、逻辑零偏差。
3. 本规范 **全局永久生效**。所有新开发、修改、重构功能必须严格对齐，无需用户重复口述业务规则。
4. 所有规则无特殊说明不得修改；存在逻辑冲突时 **优先遵循 SUNLIKE9.0 原生机制**；无法判定时 **立即询问确认**。

## 一、SUNLIKE9.0 全局系统参数统一规范

### 1. 基础全局参数（固定默认值）

| 项 | 规则 |
|----|------|
| 小数精度 | 数量 2 位、单价 4 位、金额 2 位、税率 2 位、比率 4 位；所有字段计算精度严格对齐 9.0 原生算法，不四舍五入偏差 |
| 编码规则 | 基础档案、业务单据默认沿用 SUNLIKE9.0 分段编码逻辑，支持自定义前缀、流水位数、日期拼接、自动补零 |
| 日期格式 | 统一 `YYYY-MM-DD`；时间格式 `YYYY-MM-DD HH:mm:ss`，与原生单据日期展示一致 |
| 空值规则 | 数值型字段默认空值为 **0**，文本型默认 **空**，禁止出现 null 乱码展示 |
| 状态默认值 | 所有单据/档案默认初始状态为 **【未审核】**；停用字段默认 **【否】** |

### 2. 库存核心参数（复刻原生机制）

- **库存更新逻辑**：单据审核后更新库存，反审核回滚库存，作废单据不参与库存计算。
- **负库存控制**：严格跟随系统参数开关，允许/禁止负库存完全复刻 9.0 原生校验。
- **批次/序列号规则**：批次物料强制录入批次，非批次物料隐藏批次字段，严格匹配货品属性。
- **仓库权限**：单据、档案默认携带仓库筛选，仅展示当前用户有权限仓库数据。

### 3. 单据全局参数

- 单据编号不可重复、不可手动修改，系统自动生成。
- 支持单据复制、批量新增、批量修改、导入导出，功能逻辑与 9.0 完全一致。
- **删除规则**：未审核单据可删除；已审核单据禁止直接删除，需先反审核。

## 二、SUNLIKE9.0 全单据标准流转规范（统一所有业务单据）

本规范适用于：采购单、销售单、入库单、出库单、退货单、工单、盘点单、调拨单等 **所有业务单据**，全局统一流转，无特殊特例。

### 1. 标准流转顺序（1:1 复刻原生）

```
新增 → 保存（草稿）→ 提交 → 审核 → 完成（锁定）
```

**反向流程**：已审核 → 反审核 → 修改/删除 → 重新保存提交审核

**作废流程**：未审核/已审核均可作废（受参数控制）；作废后单据终止流转，不参与账务、库存计算。

### 2. 各状态按钮显隐规则（强制统一）

| 状态 | 显示 | 隐藏 |
|------|------|------|
| 草稿（未提交） | 保存、提交、删除、作废 | 审核、反审核、关闭 |
| 已提交（未审核） | 审核、作废 | 保存、删除、提交 |
| 已审核 | 反审核 | 新增、删除、修改、提交；所有业务字段锁定只读 |
| 已作废/已关闭 | — | 所有操作按钮；页面纯只读展示 |

### 3. 单据核心联动规则（原生独有逻辑）

- **审核后**：所有表头、表体字段全部只读锁定，禁止任何修改，仅可查看、导出、打印。
- **反审核后**：解除锁定，恢复可编辑状态，库存、账务数据同步回滚。
- **单据引用锁定**：被下游单据引用的上游单据，禁止反审核、禁止作废，弹出原生提示文案。
- **数量金额联动**：数量、单价、金额、税额、价税合计联动计算，公式完全复刻 SUNLIKE9.0 原生算法，无自定义计算逻辑。

## 三、SUNLIKE9.0 字段联动/显隐/只读统一规则

### 1. 基础档案通用规则（货品、客户、供应商、分类等）

- **停用 = 是**：档案灰色展示，禁止新增单据选用，仅支持历史数据查询。
- **编码字段**：唯一不可重复，保存时全局校验重复，提示文案对齐原生。
- **名称字段**：非空必填；编码 + 名称为基础档案核心唯一标识。
- **分类层级**：上层分类联动筛选，禁止选择自身及下级分类，规避层级闭环。

### 2. 单据表头通用联动

- 单据日期默认取当前系统日期，可手动修改，修改后不影响历史计算数据。
- 往来单位选择后，自动回填默认联系人、电话、地址、结算方式等原生默认信息。
- 仓库选择后，联动筛选对应仓库库存数据、库位数据。

### 3. 单据表体通用联动

- 选择货品后，自动回填规格、单位、默认单价、税率、货品属性，完全复刻原生回填字段。
- 数量变更自动重算金额、税额，单价变更同步联动修正，精度匹配系统参数。
- 必填为空校验、重复行校验、负数数量单价校验，提示弹窗与原生一致。

### 4. 全局只读/必填统一规则

- **系统自动生成字段**（创建时间、更新时间、单据编号）：全程只读，用户不可编辑。
- **核心业务字段**（编码、名称、单据日期、往来单位、货品、数量）：保存前必填，空值拦截。
- **辅助备注、扩展字段**：非必填，默认空值。
