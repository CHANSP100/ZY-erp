# 仓库（FasECB / 表 MY_WH）

## 界面

- **左侧**：仓库资料表单（新增/存盘）
- **右侧**：仓库列表，双击行载入编辑
- **开窗**：部门、上层仓库（LookupField + LookupModal）

## 字段（首期）

| 字段 | 说明 | 必填 |
|------|------|------|
| WH | 仓库代号 | 是 |
| NAME | 名称 | 否 |
| DEP | 部门 | 否（开窗） |
| UP_WH | 上层仓库 | 否（开窗） |
| ADR | 地址 | 否 |
| TEL_NO | 电话 | 否 |
| STOP_DD | 停用日期 | 否 |
| REM | 备注 | 否 |
