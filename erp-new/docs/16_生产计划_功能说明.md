# 16 生产计划（MrpAA / MF_JH + TF_JH）

## 路径

- 页面：`/mrpaa`
- 表头：`MF_JH`
- 表身：`TF_JH`
- 对照表：`analysis/字段对照/生产计划.md`（✅ 已确认 2026-05-27）

## 本期功能

**表头：** 计划单号、计划日期、需求日期、部门、业务员、受订单号、客户、客户订单号、单据类别、批号、结案、备注

**表身：** 品号、品名、特征、仓库、单位、计划数量、预交日、批号、配方号、受订单来源、对方货号、行结案、备注

**业务：**

- 列表查询 + 新增/编辑/删除
- 审核 / 反审核（DEV-01 标准流转）
- **从受订单转入**（已审核、表身未合并计划 `JH_ID<>T`；数量默认未交量）
- 审核后回写受订表身 `TF_POS.JH_ID='T'`

**本期不做：** 合同编号、工程案号、受订合并选项（对照表标「不用」）；转制令/采购/请购（二期）
