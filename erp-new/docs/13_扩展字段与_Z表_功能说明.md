# 扩展字段与 _Z 表 — 功能说明

> 方案：`analysis/DEV_07_扩展字段与_Z表_方案说明.md`  
> 状态：**验收通过**（2026-05-25）

## 功能概述

为明细网格、单据表单、列表页表格提供「添加字段」能力，支持 SQL 展示列与 `_Z` 物理扩展表。

## 三类场景

| 场景 | 入口 | 能力 |
|------|------|------|
| 列表页表格 | 右键 → 添加字段 | SQL + 展示格式，不落库 |
| 明细网格 | 右键 → 添加字段 → 表头/表身 | 录入框 / 下拉 / SQL，落 `_Z` |
| 单据表单 | 表头/表身区右键 → 添加字段（已接入 ErpBillPage / Kingdee 单据编辑） | 录入框 / 下拉 / SQL，落 `_Z` |

## 验收步骤

1. 管理员登录，打开销售订单明细（`/so` 明细 Tab）
2. 表头右键 → 添加字段 → 表身 → 录入框字段，保存后检查 MSSQL `TF_POS_Z` 是否创建
3. 打开销售订单列表（`InvAD_BILL`）→ 添加字段仅 SQL + 展示格式
4. 中类（`/indx`）→ 表身菜单灰色
5. 必填字段空值保存应拦截（单据 save 接入后）

## 验收结论

**通过**（2026-05-25）：明细网格表头/表身添加字段、列表页 SQL 简化模式、`_Z` 表自动创建。

## 下拉框（select）

| 来源 | 配置 | 落库 |
|------|------|------|
| 固定选项 | `select_config.mode=static`，`options[{value,label}]` | 选中 value → `_Z` |
| 表/视图 | `select_config.mode=table`，`table_name` | 下拉第 **1 列** → `_Z`；第 2 列仅显示 |

运行时选项 API：`GET /api/ext-field/table-select-options/:tableName`

**档案编辑**：`ErpArchiveExtFields.vue` 已接入客户/货品/中类/部门/仓库/员工编辑窗，自动渲染扩展字段（录入/下拉/SQL 只读）。

**单据表单**（2026-05-25）：`ErpBillHeadExtFields` + `ErpBillLineTable` 已接入九单/订单/请购；存盘 payload 携带 `ext_fields`。`ErpBillPage`（MF_PSS 六单）与 `ErpKingdeeBillEdit`（订单/请购）表头卡片、表身明细区支持管理员右键「添加字段 → 表头/表身」，保存后自动刷新扩展列。
