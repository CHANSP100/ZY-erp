# 部门（FasED / 表 DEPT）

## 界面

- **左侧**：部门树（按 `UP` 上下级）
- **右侧**：部门列表，点击树节点筛选下级
- **新增/修改**：弹窗录入，双击列表行可编辑

## 字段（首期）

| 字段 | 说明 | 必填 |
|------|------|------|
| DEP | 部门代号 | 是 |
| NAME | 名称 | 否 |
| ENG_NAME | 英文名称 | 否 |
| UP | 上层部门 | 否（下拉选择） |
| STOP_DD | 停用日期 | 否 |
| REM | 备注 | 否 |

## 验收清单

- [x] 树能展开，层级与旧系统一致
- [x] 新增部门，选上层、填停用日期，存盘成功
- [x] 双击行修改名称，存盘成功
- [x] 重复代号提示「已存在」
