# DEV-01 单菜单开发规范

> 每个菜单必须走完五阶段。本文定义每阶段的输入、输出、完成标准。

---

## 阶段 ① 资料齐

### 必备资料

| 菜单类型 | 截图 | 口述 txt | 表名来源 |
|----------|------|----------|----------|
| 基础资料 | 列表 + 表单（全屏） | 可选 | DATAEX / refactor_master_menus |
| 单据 | 表头 + 表身（可两张） | **强烈建议** | MF + TF 表 |

### 截图命名（推荐）

```
旧ERP文件/截图/单据/销货单_01_表头.png
旧ERP文件/截图/单据/销货单_02_表身.png
```

索引文件：`analysis/screenshot_manifest.json`（AI 维护清单）。

### 完成标准

- [ ] 菜单代码、中文名、MF/TF 表已明确
- [ ] 截图覆盖表头可见栏位 + 表身列标题
- [ ] 无截图时：您书面说明「与 xxx 菜单布局相同，差异：…」

**缺资料 → BACKLOG 标「待补充」，停止。**

---

## 阶段 ② 字段对照表

### 产出路径

```
analysis/字段对照/<菜单中文名>.md   ← 从 STD-01 裁剪 + 截图补行
```

例：`analysis/字段对照/销货单.md`

### 写法

遵循 [DEV_02](./DEV_02_字段对照表规范与模板.md)；字段中文与组件类型须与 [STD-01](./STD/01_全局字段字典_销售链.md) 一致。

### 单据额外章节（必填）

1. **转入规则**：从哪些单转入、开窗条件、带入哪些栏
2. **回写规则**：存盘后更新哪张表哪个字段
3. **计算规则**：税额、合计、未交量/可退量等
4. **阶段划分**：本期做 / 二期做 / 不做（须您确认）

### 完成标准

- [ ] 表头：截图每个可见标签一行
- [ ] 表身：每个列标题一行
- [ ] 按钮/页签/勾选框占行（如「已分析注记」「结案」）
- [ ] 不确定项标「待确认」，不省略

---

## 阶段 ③ 您确认字段

### 您需要做的

1. 打开 `analysis/字段对照/<菜单>.md`
2. 检查：有无漏栏、错映射、阶段划分是否合理
3. 回复：
   - **「销货单 字段确认」** — 可以开发
   - 或 **「销货单 字段修改：…」** — AI 改对照表后再审

### 门禁

| 状态 | 允许的操作 |
|------|------------|
| 未确认 | 只改对照表、只讨论 |
| 已确认 | 可写 API、页面、导入、功能说明 |

---

## 阶段 ④ 开发与导入

### 交付物清单

| # | 交付物 | 路径 |
|---|--------|------|
| 1 | SQLite 表结构（或迁移补列） | `erp-new/server/db.js` |
| 2 | REST API | `erp-new/server/index.js` |
| 3 | DB_11 导入（若有数据） | `erp-new/server/import_from_db11.js` |
| 4 | 前端页面 | `erp-new/client/src/pages/*Page.tsx` |
| 5 | 路由与菜单 | `erp-new/client/src/App.tsx` |
| 6 | API 类型 | `erp-new/client/src/api.ts` |
| 7 | 功能说明 + 验收清单 | `erp-new/docs/NN_<菜单>_功能说明.md` |

### 开发约束

- **对照表是唯一字段来源**；不得私自删栏、不得用 MVP 省略未标「二期」的栏
- 开窗统一 `LookupField` + `LookupModal`（见 DEV_03）
- 只改本菜单相关文件
- 功能说明中的验收项须来自对照表「本期做」的栏
- **金蝶单据表单**（`*FormView.vue` + `ErpKingdeeBillEdit`）：表身 `ErpBillLineTable` **必须**传 `:menu-code="menuCode"`（与 `config/fields/*.ts` 中该菜单的 `menuCode` 一致），否则表头右键「列显示设置」、列拖拽排序、表身扩展字段列均不可用

### 完成标准

- [ ] `npm run build`（client）通过
- [ ] 功能说明已写
- [ ] `Project_Status.md` 标「待验收」

---

## 阶段 ⑤ 功能验收

### 验收依据

1. `erp-new/docs/NN_*_功能说明.md` 中的验收清单
2. 对照表「本期做」的栏均可操作或只读展示
3. 您截图中的核心流程可走通（如：选客户 → 转入 → 存盘）

### 结果处理

| 结果 | AI 动作 |
|------|---------|
| 「xxx 通过」 | BACKLOG ✅、Project_Status 更新 |
| 「xxx 不通过：…」 | 只改该菜单，回到阶段 ④ |

---

## 探索原型菜单的回补流程

对已验收但缺对照表的 9 个菜单：

```
补写 字段对照表 → 您 字段确认 → 标注「回补开发」→ 改代码 → 再验收
```

BACKLOG 状态可保持 ✅，但在对照表文件名或 Project_Status 注明 **「字段回补待验收」**。

---

## 禁止事项

- 未「字段确认」就写页面
- 一次开发多个菜单
- 用「和旧系统差不多」代替对照表
- 验收通过后在未更新对照表的情况下加字段
