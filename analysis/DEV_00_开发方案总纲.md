## 0. 前置说明（AI 必须遵守）

本系统为成熟旧版制造业 ERP，已有完整数据库、内置中文字段注释、内置菜单表、内置业务逻辑。

| 原则 | 内容 |
|------|------|
| 中文名称权威 | 字段中文、菜单中文 **以数据库注释/菜单表为主**；**禁止 AI 自创、改写、美化** |
| 冲突处理 | **库为主 → 截图补展示 → 冲突问您**；禁止自动归一别名 |
| 重构目标 | 界面全新统一美观、结构标准化；**数据模型与中文标签零擅自变更** |
| 功能分期 | 界面功能可分期；**二期须在全局字典/对照表标注**，禁止静默删减 |
| 全站统一 | 同字段 = 同位置 = 同组件 = 同文字 = 同样式（见 DEV-04） |

## 4. 数据字典标准化（STD-01）

### 4.1 数据源优先级

1. SunSystem / DB 表结构注释、DICT_FLD  
2. 菜单配置表 DATAEX  
3. 截图 + 口述 txt（界面是否展示、顺序、开窗）  
4. **冲突 → 列差异表 → 问您**

### 4.2 《全局 ERP 字段标准字典》格式

每字段一行，全站统一：

| 列 | 说明 |
|----|------|
| 表英文名 / 中文名 | 系统自带中文，改须问您 |
| 字段英文名 / 中文标签 | 同上 |
| 类型 / 长度 / 必填 | 库为准 |
| 业务说明 | |
| 前端组件 | 全局映射规则（DEV-02 + §4.3） |
| 查询 / 列表 / 弹窗编辑 | 是否 |
| 阶段 | 本期 / 二期 |

### 4.3 字段 → 组件强制映射

| 类型 | 组件 |
|------|------|
| varchar 文本 | `el-input` |
| varchar 编码/单号 | **只读**（禁止手输） |
| 外键编码（客户、品号等） | **LookupDialog 开窗** |
| numeric/int 数量金额 | `el-input-number` |
| datetime | `el-date-picker` |
| 系统枚举 | `el-select` |
| 大文本备注 | `el-input` textarea |
| 审核/单据状态 | `el-tag` |
| 创建/修改时间 | 列表展示，编辑隐藏 |

### 4.4 全站约束

- 同名字段 **全站中文含义唯一**  
- 发现别名/不一致：**只列出，不自动归一**，您确认后写入 STD-01  
- 禁止同一字段不同页面不同中文、不同样式、不同位置  

### 4.5 首期范围

**先做销售链相关表**，再扩展全 44 表。首期表清单见 [STD/01_全局字段字典_销售链.md](./STD/01_全局字段字典_销售链.md)。

单菜单对照表 = STD-01 子集 + 该菜单截图补行 + 转入/回写（DEV-02）。

## 6. 前端 UI 与页面标准（DEV-04 执行）

原则摘要（细节见 [DEV-04](./DEV_04_前端视觉与交互规范.md)）：

| 项 | 标准 |
|----|------|
| 组件库 | Element Plus |
| 布局 | 顶栏 + 左侧菜单 + 主体 + **底栏一行版权** |
| 色/字 | #165DFF 等固定色值；微软雅黑 18/16/14/12 |
| 编辑方式 | **大部份统一弹窗编辑**（`el-dialog` 两列/三列） |
| 查询区 | **列表/档案列表页** 顶部必有查询+重置（+导出二期） |
| 单据页 | 主区表头+表身；查询在 **侧栏单据列表**，不强制整页顶栏查询 |
| 按钮 | 主/次/危险三类，全站一致 |

### 6.1 页面类型（与 DEV-04 对齐）

| 类型 | 布局 | 编辑 |
|------|------|------|
| 档案/基础资料列表 | 顶查询区 + 表格 | **弹窗**新增/编辑（大部份） |
| 单据 | 宽栏表头表身 + 窄栏单据列表 | 整页录入；列表可筛 |
| 树形资料 | 左树 + 右列表 | **弹窗** |

## 7. 开发流程

### 7.1 总流程（两阶段）

```text
阶段 G  全局标准定稿
  → STD-01 销售链字段字典（草稿→您审）
  → STD-02 菜单路由
  → DEV-04 / 公共 Vue 模板（ListPage / BillPage / TreePage / LookupDialog）
阶段 M  按 BACKLOG 逐个菜单
  → 字段对照表（DEV-02）→ 您「字段确认」→ 开发 → 验收
```

**禁止：** 未 STD 定稿就批量乱做页面；**禁止** 未字段确认就写该菜单业务页。

### 7.2 单菜单五阶段（DEV-01，不变）

① 资料齐 → ② 对照表 → ③ 字段确认 → ④ 开发 → ⑤ 验收
