# DEV-07 扩展字段与 _Z 表 — 方案说明

> **状态：已确认 · 验收通过**（2026-05-25）  
> **2026-05-25 补充拍板**：下拉框仍用基本物理类型；来源二选一 — **固定选项** 或 **表/视图名**（两列假定，第 1 列落 `_Z`）。废弃「文本选择类」独立物理类型。
> **范围：跨菜单基础设施**（明细网格、单据表单、列表页表格）  
> **一期验收范围**：明细网格 + 列表页简化模式；单据表单接入列为二期

---

## 1. 用户拍板

| 项 | 结论 |
|----|------|
| 明细网格 `ErpDetailGrid` | 完整能力：表头/表身 + 录入框/下拉/SQL，**全部落 `_Z` 物理表** |
| 单据表单 `ErpBillPage`（表头 + 明细行） | 同上 |
| 列表页 `ErpListPage` 内表格 | **简化**：仅 SQL 展示列，**不落 `_Z`**；无表头/表身、无录入/下拉 |
| `_Z` 命名 | `{原表名}_Z`（如 `MF_POS` → `MF_POS_Z`，`TF_POS` → `TF_POS_Z`） |
| SQL 字段（明细/单据） | 保存时重算写入 `_Z`；**未审核每次保存重算**；**已审核读快照不重算** |
| 只读展示 | 不设单独开关；与其他字段同样展示/编辑 |
| 必填 | 三种来源均支持「是否必填」 |

## 2. 三类表格能力矩阵

| 场景 | 右键菜单 | 字段来源 | 存储 |
|------|---------|---------|------|
| 列表页表格 | 添加字段（无二级菜单） | SQL 表达式 | `erp_detail_grid_col`，查询时 SQL 计算 |
| 明细网格 | 添加字段 → 表头/表身 | SQL / 录入框 / 下拉框 | `_Z` 表物理列 + 列配置元数据 |
| 单据表头/表身 | 同上 | 同上 | 同上 |

单表档案（如中类）：表身菜单灰色；仅表头可选。

---

## 3. `_Z` 扩展表机制

### 3.1 建表

进入「增加字段」且为物理模式时：

1. 根据 `menuCode + area` 解析原表名（见 `menuTableRegistry.js`）
2. 若 `{原表名}_Z` 不存在 → 自动 `CREATE TABLE`
3. 主键/关键字段与原表一致，用于关联

示例：

| 区域 | 原表 | _Z 表 | 关键字段 |
|------|------|-------|---------|
| 受订单表头 | MF_POS | MF_POS_Z | OS_NO |
| 受订单表身 | TF_POS | TF_POS_Z | OS_NO, ITM |
| 中类 | INDX | INDX_Z | IDX_NO |

### 3.2 读写的物理列

- **录入框 / 下拉框**：用户录入 → 保存写入 `_Z`
- **SQL 表达式**：未审核每次保存重算 → 写入 `_Z`；已审核直接读 `_Z`
- **列表页 SQL 列**：不落 `_Z`；可 JOIN 已有 `_Z` 做展示

## 4. 设计表单配置项

### 4.1 列表页（简化）

| 配置 | 必填 |
|------|------|
| 字段代号 | ✓ |
| 显示名称 | ✓ |
| SQL 表达式 | ✓ |
| 展示格式（text / qty / price / amount / rate / date / datetime） | 默认 text |
| 列宽 | 可选 |

### 4.2 明细/单据（完整）

| 配置 | 说明 |
|------|------|
| 表头 / 表身 | 主子表均可选；单表表身禁用 |
| 字段来源 | sql / input / select |
| 物理类型 + 长度/精度 | 三种来源均需 |
| 展示格式 | 同列表 |
| 是否必填 | 保存校验 |
| SQL 表达式 | 来源=sql 时必填 |
| 下拉配置 | 来源=select：**固定选项**（value/label 列表）或 **表/视图名**（假定两列，**第 1 列落 `_Z`**，第 2 列显示） |
| 列宽 | 表格列 |

## 5. 技术实现要点

| 层 | 文件/模块 |
|----|-----------|
| 菜单→原表映射 | `server/menuTableRegistry.js` |
| _Z 表 DDL/DML | `server/extField.js` |
| 列配置扩展 | `server/gridConfig.js` → `erp_detail_grid_col` 增列 |
| 设计表单 | `ErpGridDesignDialog.vue`（mode: list / physical） |
| 明细网格右键 | `ErpDetailGrid.vue` + `useErpDetailGrid.ts` |
| 单据集成 | `ErpBillLineTable`、单据 save 钩子（逐菜单接入） |

### 5.1 `erp_detail_grid_col` 扩展字段

- `grid_area` — head / line / null
- `field_source` — sql / input / select
- `required` — 0/1
- `phys_type` — varchar / numeric / date / datetime
- `phys_len` — 长度
- `display_format` — text / qty / price / amount / rate / date / datetime
- `select_config` — JSON
- `z_table` — 关联 _Z 表名
- `persist` — 0=仅展示（列表），1=物理落库

## 6. 验收要点

1. 列表页（如 `InvAD_BILL`）右键添加字段：仅 SQL + 展示格式，无表头/表身
2. 明细网格（如 `InvAD`）右键：表头/表身二级菜单；单表（`OthHZYQD`）表身灰色
3. 添加录入框字段后 `_Z` 表自动创建且含关键字段
4. 添加 SQL 物理字段：未审核保存后 `_Z` 有值；已审核不再重算
5. 必填字段空值时保存拦截
6. 下拉框：**固定选项** 或 **表/视图名**（第 1 列落库）可配置并保存
