## 专用规则

### 与登入的分工

| 功能 | 归属 | 说明 |
|------|------|------|
| 登录页、Token、记住账号 | 登入（已做） | `/login`，不改 UI |
| 校验密码、停用日期 | 登入 API + PSWD | 读 PSWD，不写权限页 |
| 用户维护、菜单/数据权限 | 本菜单 | `/sys/auth` |

### 权限生效

| 触发 | 行为 |
|------|------|
| 登录成功 | 加载 PSWD1 摘要 + DEPRO + 仓库列表 |
| 打开侧栏 | 过滤无 DSP 的 PGM |
| 调用业务 API | 校验 PGM + 操作码 |
| 列表查询 | 附加部门、仓库条件 |

### 按钮与操作（本菜单）

| 按钮 | 阶段 | 说明 |
|------|------|------|
| 查询 | 本期 | 用户列表 |
| 新增用户 | 本期 | 需 SysAuth APD |
| 修改 | 本期 | 需 SysAuth UPD |
| 删除 | 本期 | 需 SysAuth DEL；禁止删当前登录用户 |
| 保存菜单权限 | 本期 | 写 PSWD1 |
| 保存部门群组 | 本期 | 写 DEPRO_SET |
| 保存仓库权限 | 本期 | 写 sys_user_wh（待确认表名） |
