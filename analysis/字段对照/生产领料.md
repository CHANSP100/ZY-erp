## SUNLIKE 扩展字段机制（FACE）

旧系统用三张表管理扩展字段；新系统 **读写 `MF_ML_Z` 与 FACE 兼容**（若账套存在），但 **本期界面不预置任何扩展列**，由用户像旧 ERP 一样自行添加。

| 表 | 作用 | 新系统 |
|----|------|--------|
| **FACE_FLD** | 字段定义（菜单、H/B、类型、落库表） | 用户「添加扩展字段」时写入；可同步读账套已有定义 |
| **FACE_EXP** | SQL 公式（联动/计算） | 对应扩展字段 `sql_expr`；令牌 **`:H.` / `:B.`** |
| **FACE_TBL** | 窗体布局二进制 | 二期（Web 不依赖） |

| FACE 字段 | 含义 |
|-----------|------|
| `MENU_NAME` | 菜单代号（账套 `MRPAG`） |
| `TABLE_SIGN` | `1`=表头（H），`2`=表身（B） |
| `TABLE_NAME` | 物理扩展表（若存在则为 `MF_ML_Z`） |
