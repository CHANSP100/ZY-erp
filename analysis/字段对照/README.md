## 字段增改约定（DEV-02 §8）

| 情况 | 做法 |
|------|------|
| 新增/修改字段 | 一律 **本期**，按栏位顺序 **插入对应序位**（`SCREEN_ORDER`），**不要**追加在本期表格末尾 |
| 对照表状态 | 改为 **⏳ 已确认**，直至您回复「\<菜单\> 字段确认」 |
| 已验收菜单 | 仅 `CONFIRMED_MENUS`（销货单、货品、销货折让）保持 **已确认**；对其增改后同样回到 **待确认** |

### 档案类（DEV-02 §10 + DEV-04 §12）

- 文件头 **已确认** = 整份对照表确认
- 列表页：查询 **2×5**（仅「查询=是」）；列表仅「列表=是」；录入在弹窗

**本期表头 → 本期表身 → 二期（均置后）**

生成器：`gen_field_mapping_docs.py` 中登记 `PENDING_CHANGE_MENUS` / `FIELD_CHANGE_MARK` 后重新生成。
