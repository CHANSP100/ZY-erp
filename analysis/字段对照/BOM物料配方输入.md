## 业务规则（已实现摘要）

| 项 | 规则 |
|----|------|
| BOM_NO | 手工录入；空时存盘建议 `母件品号-版本` |
| 审核 | **存盘即写入 CHK_MAN / CLS_DATE**（无单独审核按钮） |
| 已审核 | **仍可修改、可删除**（BOM 配方主档，非进销单据锁单） |
| 存盘 | 表身 ≥1 行；子件 ≠ 母件；同母件+版本不可重复 |
| 联动 | 选母件/子件回填名称、单位、规格、仓库、备注（备注可改） |
